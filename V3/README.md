## 组成

在整合版_v5 冻结基础上增加：

- 方向1：半横半正页按区块判方向、块内按行读、块间按位置合并，只用原图高精度缓存。
- 方向5a：并排两栏时，用局部竖向空白带切开跨栏行框，行组内先左栏后右栏；证照页不做。

方向3 与方向5b 未纳入。调用方式：`公共v6.v6(d, rules=("1","5a"))`。

冻结参数：`冻结/v6参数.json`（与 `代码/整合版优化/v3优化/v6探索/v6候选冻结/v6参数.json` 为同一份逐字节副本）。已与源文件核对冻结 sha256。

## 本目录包含什么

- 冻结参数：v6，以及它依赖的 v5、v4 参数文件与对应 sha
- 冻结清单中列出的全部代码文件（已按清单逐项核对 sha256）
- 为理解与离线复跑所必需的少量配套代码（`公共25.py`、`公共65.py`、`评分.py`）和规则冻结清单
- `复跑.sh`：在原始试验环境中离线复跑（0 次百度调用）
- `自测_冻结sha.py`：只核对快照内文件的 sha，不读数据集、不调接口

## 本目录不包含什么

数据和密钥未包含。未上传数据集、渲染图、PDF、百度缓存、预测文本、参照、日志、运行产物，以及任何可能含真实文件内容的材料。密钥只通过环境变量读取，离线复跑不需要密钥，也不要把真实值写入仓库或日志。

## 如何离线复跑

在原始试验环境中（需要本地缓存与数据集，本仓库不提供）：

```bash
bash 复跑.sh
```

脚本先核对本快照与本地冻结文件的 sha，再在无网络命名空间中运行，并清除百度相关环境变量，保证 0 次百度调用。
