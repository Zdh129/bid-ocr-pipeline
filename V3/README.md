# V3（优化成本）

本目录是整合版_v6 候选的代码与关键配置快照。

**V3（优化成本），候选版、未独立验证。** 尚未切换主路径。仓库根目录与现有说明中的版本仍是 V2，不受本目录影响。

## 组成

在整合版_v5 冻结基础上增加：

- 方向1：半横半正页按区块判方向、块内按行读、块间按位置合并，只用原图高精度缓存。
- 方向5a：并排两栏时，用局部竖向空白带切开跨栏行框，行组内先左栏后右栏；证照页不做。

方向3 与方向5b 未纳入。调用方式：`公共v6.v6(d, rules=("1","5a"))`。

冻结参数：`冻结/v6参数.json`（与 `代码/整合版优化/v3优化/v6探索/v6候选冻结/v6参数.json` 为同一份逐字节副本）。已与源文件核对冻结 sha256。

## 本目录包含什么

- 冻结参数：v6，以及它依赖的 v5、v4 参数文件与对应 sha
- 冻结清单中列出的全部代码文件（已按清单逐项核对 sha256）
- 为理解与离线复跑所必需的配套代码（`公共25.py`、`公共65.py`、`评分.py`）和规则冻结清单

- `环境.sh`、`复跑.sh`、`自测_冻结sha.py`、`自测_导入.py`、`干跑_规则样例.py`、`跑新材料.py`

## 本目录不包含什么

数据和密钥未包含。未上传数据集、渲染图、PDF、百度缓存、预测文本、参照、日志、运行产物，以及任何可能含真实文件内容的材料。密钥只通过环境变量读取，离线导入与规则干跑不需要密钥，也不要把真实值写入仓库或日志。

离线完整复跑本来就要识别缓存，本仓库不提供这些缓存。

## 环境变量（只写变量名）

从 PDF 重新走百度识别时，只在本机环境变量或未入库的 `.env` 里设置：

- `BAIDU_OCR_API_KEY`
- `BAIDU_OCR_SECRET_KEY`

可选别名：`BAIDU_API_KEY`、`BAIDU_SECRET_KEY`。先用仓库根目录的 `python -m pipeline check-env` 检查是否已设置（只打印有/无，不打印值），并在确认费用前不要真正发请求。

`环境.sh` 还会设置（指向本仓库内的副本，不是密钥）：

- `PYTHONPATH`
- `R5_MODS`
- `R5_STACK3`
- `M6_LAB_ROOT`
- `V3_ROOT`
- `REPO_ROOT`

离线完整复跑还需要（只写变量名）：

- `OCR_BAIDU_ROOT`
- `OCR_PDF_TEST_ROOT`（如需定位扫描件）
- `OCR_LAB_CHECKS`（可选；设为 `1` 时启用原机冻结校验和断网检查）
- `OCR_VERTICAL_MARGIN`（可选）

## 从零跑一份新材料

```bash
# 0. 准备本目录的模块路径（不需要密钥）
source 环境.sh

# 1. 若还没有识别缓存：按仓库根 README「如何运行」，在专用配置中打开 allow_external，
#    并同时加 --allow-external，对 PDF 生成 scheme_a 等缓存。调用百度前先确认费用。
#    密钥只用上面的环境变量名，不要写入仓库。

# 2. 离线套用方向1 与方向5a（0 次百度调用）
python3 跑新材料.py --pred 预测.json --scheme-a scheme_a目录 --out 结果.json

# 3. 核对本快照与依赖是否齐全
bash 复跑.sh
```

`bash 复跑.sh` 会先跑冻结 sha 自测、模块导入自测和规则干跑，再调用仓库副本的正式入口 `评分.py`。模块 import 不再读取测试集。没有本地缓存或未设置 `OCR_BAIDU_ROOT` 时，正式入口会明确报错并退出，不会写出成绩，也不会调用百度。路径修复细节见仓库根目录 `修复说明.md`。

## 读出率公式（本路线计分）

主口径读出率 = 对齐后匹配字数 / 参照字数。计算位置：

- `工程/output/博凯_清零/工具/计分.py` 中的 `rate`
- 汇总时也出现在同一文件的 `score`，以及 `工程/output/整合版_裸高精度底座/工具/整合框架.py` 的 `agg`
- 对齐统计来自仓库根目录 `scripts/tolerant_score.py` 的 `score_tolerant`（主口径）与 `scripts/blind20_score.py` 的 `score_system`（严格口径），底层是 `src/baidu_ocr/score.py` 的 `score_text`

各版本对照见仓库根 README「如何计分」。
