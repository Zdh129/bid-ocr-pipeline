## 如何离线复跑

在原始试验环境中（需要本地缓存与数据集，本仓库不提供）：

```bash
bash 复跑.sh            # 全部数据集
bash 复跑.sh 测试样本A 江苏   # 只跑部分
```

脚本在无网络命名空间中运行，并清除百度相关环境变量，保证 0 次百度调用。

数据集也可用环境变量指定（命令行参数优先；都不给时与原来相同，跑全部数据集）：

```bash
OCR_V2_SETS=测试样本A,江苏 bash 复跑.sh
```

synth18、synth18c、synth18d 三套的基线C 输入原放在试验机 `综合测试_2776d4b/输入/`。仓库不带数据：可用 `OCR_V2_SETS_INPUT` 指定目录；不设时自动用 `$OCR_BAIDU_ROOT` 下原试验机的同一目录。

## 新材料端到端（V2 路线）

对一份新 PDF 出 V2（候选路线第三版）结果。上游（准备、联网识别、build、方案E → 基线C）与 V3 新材料入口共用 `V3/工程/output/盲测集_v1/运行_隔离/` 下的 `run_30.py`、`predc.py` 等，识别缓存也可与 V3 共用；最后一步 `出结果_新材料.py` 直接调用 `复跑_第三版.py` 的底座（route5 → tablerow）、各层和元数据函数，按 `配置_第三版.json` 出结果。新材料没有参照，不计分。

```bash
export OCR_RUN_ISO=/路径/本份材料_运行隔离     # 必填
bash 新材料_端到端.sh 准备 /路径/材料.pdf       # 建目录、放入 PDF、拷入配置模板（不联网）
bash 新材料_端到端.sh 实跑                      # 只打印联网步骤（会花钱），不自动执行
bash 新材料_端到端.sh 离线 [V2结果.json]        # 从识别缓存起：build（如未做）→ 方案E/基线C → V2 结果
```

离线段默认输出 `$OCR_RUN_ISO/V2结果.json`（格式同 `预测/<集>.json`，每页带 meta），另写 `V2结果_元数据.json`、`V2结果_规则日志.json`；线缓存和中间文件在 `$OCR_RUN_ISO/运行/V2/`。离线 build 仍按原流程要求专用配置中的外发开关为打开状态（未改）；已有 build 产物时会跳过 build。缺目录、基线C或识别缓存时中文报错、退出码 1，不写结果。

## 路径修复

模块 import 不再做断网检查或读取测试集。正式入口 `复跑.sh` / `复跑_第三版.py` 在缺少缓存或输入时会明确报错（需设置 `OCR_BAIDU_ROOT`，必要时还有 `OCR_PDF_TEST_ROOT`），不会写出成绩。原机冻结校验和断网检查由 `OCR_LAB_CHECKS` 开启。详见仓库根目录 `修复说明.md`。
