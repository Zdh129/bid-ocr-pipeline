## 如何离线复跑

在原始试验环境中（需要本地缓存与数据集，本仓库不提供）：

```bash
bash 复跑.sh            # 全部数据集
bash 复跑.sh 博凯 江苏   # 只跑部分
```

脚本在无网络命名空间中运行，并清除百度相关环境变量，保证 0 次百度调用。
