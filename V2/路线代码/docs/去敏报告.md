# 去敏与密钥扫描报告

扫描时间（伦敦）：2026-11-19。本报告不包含任何密钥、token 或密钥片段。

## 做了哪些去敏

- 工作用根目录 `config.yaml`、`configs/config.yaml`：去掉本机绝对路径和历史审批备注中的人名；`allow_external` 保持 `false`；`project_root` 改为 `.`；数据集路径改为 `data/` 相对路径。
- 不纳入任何带 `allow_external: true` 的原 live 配置。另附关闭外发的模板：`configs/config.live.example.yaml`、`config_astra_live.yaml`、`config_hybrid.yaml`、`config_hybrid_live.yaml`（后三份仅保留模型名与费用上限等非密钥字段，供单元测试与对照，外发开关均为 false）。
- `scripts/hybrid_final_report.py` 工作副本去掉人名与原话转述。
- 密钥只通过环境变量读取：`BAIDU_OCR_API_KEY`、`BAIDU_OCR_SECRET_KEY`（与冻结代码一致）。`.env.example` 只有占位符。入口脚本可将 `BAIDU_API_KEY` / `BAIDU_SECRET_KEY` 映射到上述变量名。
- 不纳入数据集、PDF、图片、百度返回缓存、运行日志、scores 输出、截图。`.gitignore` 排除 `data/`（保留说明与模拟 fixtures）、`cache/`、`output/`（仅保留冻结清单 JSON）、`*.log`、`.env`。

## 仍保持逐字节原样的冻结快照

`rules/`（含 `baseline_c/基线C_方案E/`）、`scripts/history/`、以及与方案E 冻结清单一致的 `src/` 与大部分 `scripts/`，未改字节，以便 sha256 复核。因此其中仍可能出现：

- 原试验机绝对路径（如 `/workspace/pdf-test/baidu`），不含家目录用户名；
- 冻结记录或代码注释里的历史审批备注（含人名）；
- 源文件的 sha256 校验值（不是密钥）。

这些文件保持只读。运行请用 `python -m pipeline`，不要直接改冻结文件。

工作副本 `src/baidu_ocr/pipeline.py` 与冻结快照相同，其中有一处历史备注含人名；未改，以免破坏方案E 清单校验。
