# 冻结规则（只读快照）

本目录文件保持冻结时的逐字节原样，用于复核 sha256，不得改动。其中可能含原试验机绝对路径和历史审批备注，运行请改用仓库提供的 `python -m pipeline` 入口（会在内存中映射路径，不改这些文件）。

| 目录 | 含义 |
|---|---|
| `baseline_c/` | 基线C：方案E（文档解析＋高精度含位置＋改进⊗＋发票重排等）以及乙′/门控所用的版面规则（`variants_blind.py`、`layout_posthoc.py` 等）。完整方案E 代码快照在 `baseline_c/基线C_方案E/`。 |
| `round1/` | 第1轮冻结路线：乙′ 版面改写、合计行切分、表头定位、栏位纠正、竖排融合。 |
| `round2/` | 第2轮冻结路线：在第1轮上增加单列明细合计切分、合计行纳入明细区下沿、表头带词表切分、栏位纠正边界守卫。 |
| `round3/` | 第3轮冻结路线（当前推荐）：第2轮＋F4 格内折行续行归格（`lp3.py`，长单价等数字折行的尾数接回上方格）＋F5 页首行坐标复位（`head_fix.py`，排在「购买方：/销售方：」前但坐标在其下方的段挪回）。另附 `冻结文件_sha256.txt`。 |
| `round5/` | 第5轮整合路线冻结副本（route5.py＋layout_prior.py＋consistency_check.py，`冻结_sha256.txt` 可核对）。运行依赖试验机路径，未接入 `python -m pipeline`。 |
| `round5_method6/` | 第5轮方法6 表格行拼回：整合路线之后的后处理，只改空白和换行，用来恢复明细表的行和栏位结构。见 `冻结记录.md`。 |

每目录含 `冻结记录.md` 与 `冻结记录_sha256.txt`。核对：

```bash
python -m pipeline verify
# 或
python scripts/verify_frozen.py
```

工作用、已去敏的默认配置是仓库根目录 `config.yaml`。不要用冻结快照里的 `*_live.yaml` 做新的外发复测。
