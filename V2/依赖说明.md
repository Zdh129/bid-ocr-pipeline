## 环境变量（只写变量名，密钥不要写入仓库或日志）

离线导入自测不需要密钥。若要从 PDF 重新走百度识别，只在本机环境变量或未入库的 `.env` 里设置：

- `BAIDU_OCR_API_KEY`
- `BAIDU_OCR_SECRET_KEY`

可选别名：`BAIDU_API_KEY`、`BAIDU_SECRET_KEY`。

本目录 `环境.sh` 还会设置（指向仓库内副本，不是密钥）：

- `PYTHONPATH`
- `R5_MODS`
- `R5_STACK3`
- `M6_LAB_ROOT`

## 从零跑一份新材料

1. 按仓库根 README「如何运行」生成识别缓存（调用百度前先确认费用；仓库不附带 PDF、参照或缓存）。
2. 在有本地缓存的试验环境中，用原入口离线套规则（0 次调用）：

```bash
source 环境.sh
bash 复跑.sh
```

若只检查本仓库是否已补齐运行源码：

```bash
source 环境.sh
bash 复跑_仓库.sh
```

原 `复跑.sh` / `复跑_第三版.py` 仍按原试验机路径做网络隔离和冻结校验，完整复跑需要本地缓存。
